# Glean

Glean é um aplicativo para Windows feito para baixar vídeos, áudios e postagens de plataformas populares, com uma interface simples e prática.

---

## Recursos

-  **Baixe vídeos e áudios do YouTube**
-  **Suporte a playlists do YouTube**
-  **Baixe postagens do Instagram**
-  **Baixe vídeos do TikTok**
-  **Baixe postagens do X**
-  **Importe listas de URLs por arquivo `.txt`**
-  **Detecta links copiados automaticamente**
-  **Histórico de downloads**
